- Codex 하위 에이전트도 입력창 위 백그라운드 작업 줄에서 확인할 수 있어요. 작업을 누르면 해당 카드로 이동해요.
- 서브에이전트의 실행과 대기를 같은 카드에 표시하고, 실제 작업이 끝나면 완료 상태로 바뀌어요. 에이전트를 닫아도 완료 결과와 실패 상태를 유지해요.
- 백그라운드 에이전트가 작업 중일 때 Codex가 유휴 상태로 종료되지 않도록 개선했어요.
- Sudal CLI에서 `--provider antigravity`로 Antigravity 탭을 만들고 작업을 전달할 수 있어요. 기존 `agy` 이름도 사용할 수 있어요.
- Sudal에서 사용한 Antigravity의 토큰과 요청 수를 사용량 화면에 반영해요. Argon 비용은 공식 API 가격으로 환산하며 캐시 입력은 별도 단가로 계산해요.
- Windows에서 개발용 앱이 설치된 Sudal의 알림 이름과 충돌하지 않도록 앱 식별자를 분리했어요.
