- 교차 리뷰에서 Claude Code·Codex·Antigravity와 모델을 직접 고를 수 있어요. 같은 CLI도 별도 세션에서 독립적으로 리뷰할 수 있고, 결과는 원래 대화의 카드로 돌아와요.
- 설치되지 않은 리뷰어는 선택할 수 없도록 표시하고, CLI를 다시 탐색할 수 있어요. 리뷰어를 바꾸면 모델 선택도 해당 CLI의 기본값으로 초기화돼요.
- 리뷰 선택 창이 열린 동안 배경의 도구가 Enter로 승인되거나, 분할 화면·탭 이동 단축키와 새 승인 요청이 포커스를 빼앗는 문제를 수정했어요.
- 이전 대화 불러오기 버튼에 화살표·로딩 표시를 추가하고, 좁은 화면에서도 영역을 넘지 않도록 개선했어요. 한국어 로딩 문구도 “대화 불러오는 중…”으로 다듬었어요.
- Antigravity 구독 한도의 모델명 앞에 가운데 점을 붙이고 기간 항목을 들여써 더 쉽게 구분할 수 있어요. 리뷰 카드에도 Antigravity 이름이 올바르게 표시돼요.
