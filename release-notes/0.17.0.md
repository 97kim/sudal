- Codex 채팅에서 `/plan`으로 플랜 모드를 켜고 끌 수 있어요. 현재 모드는 입력창 위에 표시되며, 계획 중 Codex가 묻는 질문에도 채팅에서 답할 수 있어요.
- `/goal`로 자동 목표와 토큰 예산을 설정하고, 진행 상태 확인·일시정지·재개·해제를 할 수 있어요. 자동으로 이어지는 작업에도 권한 정책과 동시 실행 제한이 적용돼요.
- Codex의 `/review` 결과를 채팅에서 확인하고, `/compact`로 같은 세션의 대화를 압축할 수 있어요. 압축 완료 표시와 컨텍스트 게이지도 함께 갱신돼요.
- `/usage`·`/mcp`·`/status` 등 명령 결과를 카드와 목록으로 보여 줘요. 사용 한도, MCP 연결·도구, 백그라운드 프로세스, 훅·플러그인·메모리 정보를 더 쉽게 확인할 수 있어요.
- 슬래시 명령 목록에 Sudal·Codex·Claude·Antigravity 출처를 표시해요. 아직 지원하지 않는 Codex 명령은 모델에게 전송하지 않고 안내하며, 새로운 제어 기능에 CLI 업데이트가 필요하면 알려 줘요.
- 목표 완료·서버 종료·탭 닫기 후 다음 작업이 계속 대기하거나, 늦은 조회 응답이 완료된 목표를 다시 실행 중으로 표시하던 문제를 수정했어요. 초기화 중 닫은 탭에서 뒤늦게 목표나 예열이 시작되는 문제도 막았어요.
