- Codex에서 `/fast`만 입력하면 오류 대신 빠른 처리 켜기·끄기 선택창이 열려요. 선택창을 여는 것만으로 설정이 바뀌지는 않으며, `/fast on`·`/fast off`로 바로 적용할 수도 있어요.
- 빠른 처리 설정을 요청하는 동안 중복 실행을 막고, 실패하면 안내를 확인한 뒤 다시 시도할 수 있어요. 창을 닫았다 다시 열어도 이전 요청의 결과가 새 창에 섞이지 않아요.
- 권한 변경·대화 이름 저장·모델 선택 등에서 오류가 발생했을 때 내부 통신 경로와 `MsgError:` 같은 문구를 빼고 실제 안내만 표시해요. 권한·파일 경로 등 판단에 필요한 오류 상세는 그대로 보여 줘요.
