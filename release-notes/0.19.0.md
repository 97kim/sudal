- 하네스를 대화 흐름에서 사용할 수 있도록 바꿨어요. 상단에서 현재 작업을 확인하고, 대화 속 제안에서 목표·완료 조건·직접 확인한 근거를 검토해 적용할 수 있어요. 프로젝트 구성과 작업 상세는 패널에서 관리해요.
- `/compact`가 끝나면 이전 대화를 기본으로 접고 압축 이후 기록부터 보여줘요. 이전 대화는 필요할 때 펼칠 수 있고, 검색 결과를 선택하면 해당 기록을 불러와 이동해요. 원본 대화 기록은 그대로 보존돼요.
- 대화에 다시 들어올 때 경량 캐시와 파일 위치를 활용해 과거 본문을 반복해서 읽는 작업을 줄였어요. 캐시가 없는 최초 조회는 원본을 한 번 읽으며, 캐시가 손상되거나 기록이 바뀌면 원본에서 복구해요.
- 이전 기록을 불러오는 도중 접거나 새로 압축했을 때 늦은 응답이 대화를 다시 펼치지 않도록 했어요. 펼치기 실패 후 재시도와 인자가 있는 `/compact` 요청 표시도 보완했어요.
- 지원되는 로컬 HTML 시안 표시를 ‘시안 열기’ 버튼으로 보여줘요. 허용된 시안 경로만 열고, 코드 예시 안의 표시는 원문으로 유지해요.
- 작업 조건이 바뀐 뒤 오래된 확인을 적용하거나 다른 작업에 근거가 연결되지 않도록 확인 절차와 상태 동기화를 보완했어요.
