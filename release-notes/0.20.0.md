- 하네스 상세를 오른쪽 패널의 ‘작업’ 탭으로 옮겼어요. 채팅을 가리지 않고 컨텍스트·파일·작업을 전환할 수 있으며, 상단 현재 작업 요약은 그대로 유지돼요.
- 완료 조건을 목록으로 정리하고 선택한 조건 바로 아래에 확인 방법과 근거를 보여줘요. 명령 검증에서만 체크박스를 표시하고, 조건 제목으로도 여러 조건을 선택할 수 있어요. 직접 확인 중 다른 조건을 눌러도 모드가 유지돼요.
- 작업 완료 버튼을 하단에 고정했어요. 작업 시작·조건 저장·하위 화면 취소 후에는 작업 화면으로 돌아오며, 패널을 접었다 펼쳐도 작성 중인 프로젝트 설정을 보존해요.
- Esc 키가 검색창·모달·다른 분할 화면·최대화 편집기와 간섭하지 않도록 처리했어요. 패널을 명시적으로 열 때만 포커스를 옮기고, 임시로 펼친 패널을 닫으면 이전 탭과 접힘 상태를 복원해요.
- 하네스의 로딩·조회 실패·비활성 상태를 구분하고, 조회 복구와 작업 성공 후 오류 표시를 정리했어요. 설정 패널의 중첩 스크롤도 제거했어요.
