- Codex·Claude 내부 서브에이전트의 저장된 대화를 부모 옆의 읽기 전용 탭에서 볼 수 있습니다. 같은 서브에이전트를 다시 열면 기존 탭으로 이동합니다.
- 서브에이전트가 실행 중일 때는 조회 중인 탭에 새로 저장된 대화와 도구 실행 기록을 약 1초마다 자동으로 반영합니다.
- 부모 대화로 돌아가기와 나란히 비교하기를 지원하고, 열어 둔 조회 탭은 앱을 다시 시작해도 복원합니다. 조회 탭을 닫아도 원본 대화는 유지됩니다.
- 완료된 내부 서브에이전트는 사이드바에서 숨깁니다. 부모 대화의 Agent·Task 카드에서 **대화 보기**를 누르면 다시 열 수 있습니다.
- 긴 대화에서 메시지의 높이를 잘못 측정해 스크롤이 크게 튀는 문제를 수정했습니다. 서브에이전트의 새 기록이 도착하거나 기록을 새로고침해도 읽던 내용을 비우거나 맨 아래로 강제로 이동하지 않습니다.
